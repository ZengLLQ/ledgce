# ADR 0004: Monochromatic Restraint and Starlink Design Direction

## Context
Generic SaaS financial dashboards rely on aggressive red/green traffic lights, neon gradients, and marketing illustrations. Financial infrastructure engineers need a quiet, technical, highly focused environment where typography, density, and tabular alignment communicate operational truth.

## Decision
1. Adopt a strict monochromatic palette consisting of `#000000`, `#050505`, `#0D0D0D`, `#141414`, `#1B1B1B`, `#262626`, `#3A3A3A`, and `#FFFFFF` with neutral gray tints.
2. Financial states are represented by text labels, icon geometry, and position rather than pure color coding.
3. Typography uses the NeoDIN/DIN-like clean sans-serif stack with monospaced tabular numerals for financial data.
4. Replace all consumer broadband copy and dish imagery with genuine financial ledger graphics (balance zero-sum vectors, outbox pipelines, and reconciliation trees).

## Status
Accepted and Implemented.
